# post.md template

```markdown
# Posts — <product>

## X (three openings, each ≤ 260 chars)
**A.** <payoff in the first line>
<how, one line>
<link, only if the user asked for one>

**B.** <a question the product answers>
...

**C.** <a before/after>
...

## LinkedIn
<Problem in plain language.>

<2–3 short paragraphs, first person: what you built, the part you are proudest
of, one thing you learned.>

<link, only if the user asked for one>

## Product Hunt
**Tagline (≤ 60 chars):** <...>

**First comment:**
<Who you are, why you built it, what is different, one question for readers.>
```

Rules: payoff before the product name; only claims from `facts.md`; at most two
hashtags; match `--style` (bold = punchy, calm = measured, techy = precise,
warm = friendly).
